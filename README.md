# The Love Walk 2026

Projeto do site oficial The Love Walk 2026 — A caminhada que nos une.

A implementação completa está no arquivo `the-love-walk-2026.zip`. Baixe o arquivo, extraia a pasta e siga o `README.md` incluído no pacote para instalar o frontend, o backend FastAPI, preparar os modelos de reconhecimento facial e indexar fotografias autorizadas.

## Identidade visual

- Roxo: `#211038` / `#170A2A`
- Laranja: `#D96B35`
- Branco suave: `#F5F2F7`
- Galeria preparada para aproximadamente 600 fotografias.
- Busca facial requer configuração local/servidor, modelos e indexação; não estará ativa apenas por publicar a página estática.

## Privacidade

A busca facial envolve dados biométricos sensíveis. Antes de publicar, configure HTTPS, controle de acesso, política de retenção e remoção dos dados, e revise a base legal e os avisos conforme a LGPD.
