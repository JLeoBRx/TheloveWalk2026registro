# Fotos da FJU Night — A Noite da Herança

Coloque aqui as fotografias **autorizadas para publicação**, **direto nesta pasta**. Não precisa
separar em pastas: o álbum mostra todas juntas, em ordem de horário da foto.

- **Como enviar pelo GitHub:** abra esta pasta → *Add file* → *Upload files* → arraste as fotos →
  *Commit changes* na branch `main`. O site se atualiza sozinho em alguns minutos.
- **Formatos:** JPG, JPEG, PNG, WebP e RAW de câmera (CR2, CR3, NEF, ARW, DNG…).
- **Limites do GitHub:** até 25 MB por arquivo pelo navegador; até 100 MB por `git push`.
- **Originais preservados:** o sistema nunca altera estes arquivos; o botão *Baixar* entrega o original.
- **Remover uma foto:** apague o arquivo ou oculte pelo painel `/admin`.
- Se alguma subpasta for criada sem querer, as fotos dela também entram no mesmo álbum.
